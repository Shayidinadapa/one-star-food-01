An alien tourist gives planet Earth a one-star review — and still admits the food was excellent.

`main.ts` writes a single sentence (159 characters) to `/output/entry.txt`: a one-star review of Earth from an alien visitor who was billed for breathing, had its saucer towed, and got rained on without warning — but found the satay so good it would come back, pay the fine, and eat it twice.

## Run

```sh
node main.ts
cat /output/entry.txt
```
